使用指南

保存你需要的显示器配置。

DisplayPreset 专注于一项任务：在 macOS 上保存和恢复显示器配置。

1. 安装并打开

从 Mac App Store 安装 DisplayPreset，并在需要管理的显示器都已连接时打开应用。应用读取 macOS 提供的显示器信息。

2. 查看当前配置

主界面会列出 macOS 当前检测到的显示器，并显示当前显示器配置。

3. 保存配置

选择“保存”，输入容易识别的名称，例如“桌面”或“出差”，然后确认。配置会保存在你的 Mac 上。

4. 恢复配置

选择已保存的配置并点击“应用”。DisplayPreset 会请求 macOS 恢复该显示器配置。如果有显示器不可用，请先重新连接后再试。

5. 重命名或删除

通过配置操作菜单重命名配置，或删除不再需要的配置。删除只会影响本地保存的配置。

6. 导入和导出

通过配置菜单将配置导出为 JSON 文件，用于备份或迁移。导入之前导出的 JSON 文件，并确认要添加的配置。应用只会访问你选择的文件。

7. 解锁更多配置

免费版支持保存一个配置。“无限显示器配置”是一次性购买项目，参考价格为 $1.99，最终价格以 App Store 显示为准。在另一台使用同一 App Store 账户的 Mac 上，可以使用“恢复购买”。

当前范围

这个 MVP 只管理显示器配置，不要求账户或服务器，也不能恢复 macOS 当前无法检测到的显示器。
