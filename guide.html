User guide

Save the display setup you need.

DisplayPreset is designed around one focused task: saving and restoring display profiles on macOS.

1. Install and open

Install DisplayPreset from the Mac App Store and open it with the displays you want to manage connected. The app reads the display information that macOS makes available.

2. Review the current setup

The main screen lists the displays currently detected by macOS and shows the active display configuration.

3. Save a profile

Choose Save, enter a meaningful name such as “Desk” or “Travel”, and confirm. The profile is stored locally on your Mac.

4. Restore a profile

Select a saved profile and choose Apply. DisplayPreset asks macOS to restore the saved display configuration. If a display is unavailable, reconnect it first and try again.

5. Rename or delete

Use the profile actions menu to rename a profile or delete one you no longer need. Deletion affects only the local saved profile.

6. Import and export

Use the configuration menu to export profiles as JSON for backup or migration. Import a JSON file that you previously exported and confirm the profiles you want to add. The app accesses only the file you choose.

7. Unlock more profiles

The free version supports one saved profile. The one-time “Unlimited Display Profiles” purchase is $1.99 as a reference price; the final price is shown by the App Store. After purchasing, use Restore Purchases on another Mac signed in to the same App Store account.

Current boundaries

This MVP manages display profiles only. It does not require an account or a server, and it cannot restore a display that macOS does not currently detect.
