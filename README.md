# DisplayPreset website

This repository contains the static marketing, support, privacy, terms, and user-guide pages for DisplayPreset.

The current App Store MVP is focused on saving and restoring display profiles on macOS. The website documents the product and links to the Mac App Store; it does not process payments or provide a remote authorization service.

## Pages

- `index.html` / `zh-hans.html` — English and Simplified Chinese product pages
- `guide.html` / `zh-hans-guide.html` — user guides
- `privacy.html` — privacy policy
- `terms.html` / `zh-hans-terms.html` — terms of use
- `support.html` — support and troubleshooting

The site is published as a GitHub Pages static site at https://displayset.github.io/.
